# Scriptwriting gates

Build a script people understand on the first listen and have a reason to keep watching. Use for short-form organic, sponsored and promotional videos, including agencies, vehicles, fitness, services, education and technology. Adapt to the audience and assignment, not to a fixed industry or creator. Longer formats use the same checks at section level, with sentence-level evidence; do not force a short-video runtime on them.

This is **one skill with supporting references**, not several plugins to install. Read [workflow](references/workflow.md), [gates](references/gates.md) and the entire [Humanizer](references/humanizer.md) before drafting or reviewing. These are the complete operating instructions. For structured validation, use [packet contract](references/packet-contract.md).

## Non-negotiable decision order

Verified facts and real authority → the chosen reference's actual emotional engine → the largest credible useful outcome → rising sentence value and intelligible transitions → real filmable proof → separate final-cut clearance.

The gates judge the script; they are not 30 sentence slots. Do not fabricate a number, personal result, credential, customer story, urgency, demo, reference winner, approval or completed check. Do not weaken a supported outcome into generic cautious prose. Scope the promise accurately from the start instead of inflating it and spending the next sentence retracting it. Required disclosures and material qualifications cannot be hidden in a resource if the spoken promise would otherwise mislead.

## Select the mode and profile

- **New:** establish the brief and write from verified sources.
- **Revision, hook swap or length change:** obtain the exact current version; preserve locked wording and facts; rerun the whole review, not just changed rows.
- **Audit:** findings only. Do not rewrite or modify the original unless the user requests it.

Record audience, goal, topic, platform, duration, tone/voice samples, offer, resource/CTA, sponsorship, deadline, source access, exact locks and historical-library access. Use the supplied audience: a car buyer is not an agency owner; a fitness beginner is not an AI user. A specialist brief may intentionally be narrow. Widen avoidably exclusionary framing, never actual product scope.

Default style: viewer-first; short spoken opening, roughly 10–18 words; natural connectors; no three-item recital; no spoken links or literal long prompts; no editing cues inside narration. These are defaults, not alleged universal audience findings. Explicit user voice/configuration may allow first person, domain terms or dash style. Record deviations before validation; they are **declared customizations**, not unexplained strict-standard passes. Never infer permission from a sentence the agent itself wrote. Accuracy, honest evidence and permission boundaries cannot be overridden by style preferences.

## Run the full workflow

1. **Truth sheet:** separate locked facts, translatable requirements, optional marketing copy and unsupported/risky claims. Verify every number, price, deadline, capability and attribution. Survey the whole relevant offer, not only the first two features. Maintain claim → source/date → evidence type → wording/scope → result.
2. **Reference retrieval:** inspect two or three authorized voice/approved examples and, where available, 5–10 measured candidates. Approval is not performance. Read actual transcripts, comparable observation windows and sponsorship context. Select one primary parent and suitable supports; examine closest analogue, available weak/repeated control and recent published plus approved-unpublished coverage. Transfer the actual device, not a copied hook or a distant money theme.
3. **Concept lock:** name who forwards it to whom, the audience-native territory, breadth/prerequisites, reference device, optional supported upward reveal, meaningful change and actual demo. Write burden/cause → intervention → result → viewer's changed role in plain language. If the angle is wrong, rebuild the concept rather than polish the hook.
4. **Hook first:** draft the opening and line two together. Apply H1–H4 to the same opening: benefit lever, emotion, understandable curiosity and relevant credibility. Give enough information for a real question, not an empty teaser. Line two strengthens or concretes the promise, never descends into smaller features. A famous name is not obligatory; real relevant evidence can establish credibility.
5. **Body:** one sentence per ladder row. Each adds capability, consequence, proof, scale, control or a meaningful next action. A useful growing task roster and deepening fear followed by earned relief are valid engines; no axis-rotation quota. Answer real promise-raised doubts through verified capabilities, preferably inline. No automatic compatibility ending, setup ritual, forced objection count or invented control.
6. **Proof and resource:** specify real starting state, exact action, readable result and consequence. Preview the result early when feasible; thread proof through the build and let the strongest earned payoff lead into the CTA. Verify a saveable artifact exists independently of engagement. Resource existence and filmability are script-stage checks; footage and distribution are separate.
7. **Spoken edit and Humanizer:** compress recitals into a true collective term without dropping useful meaning or broadening coverage. Audit all 33 patterns. Preserve factual/locked-wording parity. Run draft → self-critique → final edit internally, then an explicitly recorded human or synthetic rehearsal. A word count is not measured timing; a synthetic read is not human listening.
8. **Full review:** display every G1–G30, H1–H4, D1–D7 and 33 Humanizer result, with exact evidence. Print sentence ladder, five audience states, truth sheet, parity, rehearsal and production checks. Run G26 and G30 last from the intended viewer's seat. Correct solvable failures and rerun after any edit.

## Evidence and honest cold starts

Use only permitted user/public sources; an unavailable or denied library is not permission to access another profile or private database. Without measured relevant history, provide a useful **PROVISIONAL DRAFT — winner transfer unverified**, keep G21/G28 BLOCKED and explain how actual transcripts and comparable observations would clear them. Do not invent analytics or call cold start N/A. Lack of a control after a documented search is disclosed uncertainty, not automatically a permanent block when a defensible measured parent exists.

PASS means actually checked and supported; REVISE means not met; BLOCKED means required evidence is unavailable; N/A needs a genuinely topic-specific reason. A missing beginner benefit is not N/A. Count these separately, not as a fake 30/30 score. A useful WIP may be shown clearly labelled, never presented as finished or fully passed. A locked line can have a finding without being silently changed.

Run the bundled checker when Python 3 is available:

```bash
python3 scripts/validate.py --packet /absolute/path/review.json --root /absolute/path/artifacts
```

It checks coverage, quotation receipts, artifact existence, sentence coverage and mechanical contradictions. It **does not prove persuasive quality, source truth, measured performance, actual listening or real approval**. Its G25 mechanical subset does not replace 33 editorial checks. Without execution tools, perform the visible review and explicitly say mechanical validation was not run. Never claim a validator pass from a command pasted into notes.

## Deliver and preserve

Use [the output contract](references/packet-contract.md): current script first, full review below, notes/resources outside spoken copy, older versions below a dated superseded divider with real feedback and approval status. Approval attaches to the exact version, not a later edit. Record it only in a user-authorized local library and read it back; external storage needs separate current authorization. Approved-but-unmeasured writing stays distinct from published winners.

Final production requires the actual assembled cut reviewed at phone scale with crop, subtitles, voice timing, real platform overlays, normal-speed audiovisual playback and timestamped proof findings. Identify exact final bytes/version; changes invalidate clearance. Isolated assets, generated rehearsal and still frames do not certify the reel. Missing final footage does not circularly block script-stage approval.

Do not send, upload, publish, schedule, pay, install integrations or change accounts as a side effect of using this skill. A script approval and a validation result are not permission for any of those actions. Resources and CTA fulfillment must be verified before publication is claimed ready.
